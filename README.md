# E-Commerce Sales & Operations MIS Dashboard

An Excel-based Management Information System (MIS) developed to transform raw e-commerce order data into structured management reports, KPI analysis, interactive dashboards, and automated reporting workflows.

**Tools:** Microsoft Excel | VBA | PivotTables | PivotCharts | Slicers | VLOOKUP

---

## 📊 Project Overview

This project simulates a real-world MIS reporting environment for an e-commerce business.

The system processes **1,200 order records** and provides management visibility into:

- Sales performance
- Product performance
- Order status
- Customer order activity
- Referral source performance
- Payment methods
- Cancellation and return rates
- Monthly sales trends

The objective is to reduce repetitive manual reporting and provide a centralized view of operational performance.

---

## 🎯 Business Problem

E-commerce teams generate large volumes of transactional data that need to be converted into meaningful management information.

A structured MIS is required to:

- Consolidate raw order data
- Standardize and enrich business information
- Monitor operational KPIs
- Identify performance trends
- Support management reporting
- Reduce repetitive manual work

This project addresses these requirements through an Excel-based automated MIS workflow.

## 📁 Workbook Structure

| Sheet | Purpose |
|---|---|
| `01_Raw_Data` | Original order-level data and validation fields |
| `02_Master_Data` | Product master information |
| `03_Enriched_Data` | Transaction data enriched using VLOOKUP |
| `04_MIS_Report` | Management KPIs and operational metrics |
| `05_Pivot_Analysis` | PivotTable-based analysis |
| `06_MIS_Dashboard` | Interactive management dashboard |
| `MIS Control Panel` | Reporting controls and VBA automation |
